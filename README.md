### PART 4: Create Your Folder Structure

You need to create folders to organize your code. On GitHub you can't create empty folders — you create a folder by creating a file inside it. Here's how:

1. In your repo, click **Add file → Create new file**
2. In the filename box at the top, type:
`code/placeholder.md`
   - Typing the `/` automatically creates a folder called `code`
3. In the file body, type: `# Code folder - MATLAB scripts will be added here`
4. Commit with message `"Created code folder"`

Repeat for two more folders:
- `results/placeholder.md` → body: `# Results folder - plots and outputs will go here`
- `docs/placeholder.md` → body: `# Docs folder - report and references will go here`
